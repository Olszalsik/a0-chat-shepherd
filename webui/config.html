Chat Shepherd

Watches chats for stalls, auto-nudges stalled agents, and flags chats needing human input. When off, only chats that have received at least one message are monitored.

Dashboard

How often the monitor panel refreshes itself (2-120 seconds; clamped on save). Takes effect after the next status fetch.

Stall detection

Global burst throttle: at most this many auto-nudges are sent per watch tick (0 disables auto-nudging). After max auto-nudges are exhausted, the chat escalates to intervention status.

Escalation

Graceful reload

Wedge auto-recovery

A running chat that stops producing log output is "wedged". After the grace period it gets an automatic "continue" (the same nudge that fixes it manually). When remediations are exhausted and this toggle is on, the final attempt kills the hung task and re-sends the framework nudge — this loses the hung call's partial result. Max remediations 0 disables wedge auto-recovery.

Adaptive thresholds (experimental)

Opt-in: with enough fresh outcomes, nudge cooldown and wedge timing relax when remediations mostly work (≥70%) or back off when they mostly fail (<40%). Runtime-only overlay — your configured values are never overwritten; manual changes re-seed the baseline; learned values live in the plugin state and never leave the safety band.

Supervised mode (experimental)

When on, restart-resume and stalled-chat nudges are NOT sent automatically. Instead an editable draft message (tailored to the situation and the chat's classification reason) appears on the dashboard; you edit it and send it, or dismiss it. Dismissed chats are not re-drafted for 30 minutes. Wedge remediation and the goal-completion gate stay automatic.

External alerts (optional)

Fires alongside in-app notifications for intervention + restart alerts.

Chat allowlist (optional)

Comma-separated chat IDs to watch. Empty = watch all chats.

Sidebar pictograms

Tap a pictogram to pick an emoji or symbol from the dropdown. Choose none to hide the pictogram for that state.
